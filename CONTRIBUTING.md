# How to Contribute

Just send a PR, but make sure you test with real game data. Include which version of the game data you are using (disk, patched disk, steam release, etc).

Contributions are accepted under the project's licence, the GNU AGPL version 3 or later
([LICENSE](LICENSE)).

## AI Contributions Policy

I don't care if you use AI to contribute to the codebase. Don't use AI for communication or to create/write pull-requests. I don't want to read AI slop prose.
